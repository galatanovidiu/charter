Provides a secure, standards-compliant OAuth 2.1 authorization server for WordPress.

== Description ==

Charter is being built to provide OAuth 2.1 authorization-server capabilities for WordPress.

This initial development release establishes the installable plugin foundation. It does not expose OAuth endpoints, client management, token storage, or an administration interface yet.

== Installation ==

1. Upload the `charter` directory to `/wp-content/plugins/`.
2. Activate Charter through the Plugins screen in WordPress.

== Frequently Asked Questions ==

= Does version 0.1.0 provide OAuth endpoints? =

No. Version 0.1.0 is an installable development foundation. OAuth behavior will arrive in later releases.

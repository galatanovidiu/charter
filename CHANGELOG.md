# Changelog

## 0.1.0 - 2026-10-21

Initial OAuth v1 release.

- Added site-local OAuth 2.1 issuers with RFC 8414 and RFC 9728 discovery.
- Added public and confidential clients, RFC 7591 Dynamic Client Registration, and HTTPS Client ID Metadata Documents.
- Added Authorization Code with mandatory PKCE S256, opaque access tokens, rotating refresh tokens, replay containment, and RFC 7009 revocation.
- Added consent, personal Connected Apps controls, administrator client and grant governance, retention, emergency containment, and signing-key lifecycle controls.
- Added exact-handler REST protection, integration-owned resources and scopes, Multisite isolation with required network activation, permanent site-deletion cleanup, and complete plugin uninstall cleanup.
